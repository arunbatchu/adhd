## Description

[Chapter 2](../../chapters/02-the-adhd-brain/index.md) calls the ADHD reward
system an economist with a broken discount rate: rewards lose motivational
value unusually fast as they move away in time. This simulator draws both
discount curves — typical (gray, gentle) and ADHD-steep (orange, collapsing) —
from the same reward, with a red **motivation threshold** line below which
tasks simply don't start. Drag the reward marker along the delay axis and the
readout shows what each brain *feels* the reward is worth, and whether it
starts or stalls.

The four intervention chips are the chapter's strategy logic made physical:
**Today-sized piece** and **Deadline tomorrow** move the payoff near *now*;
**Body double** and **Make it a game** lift the whole curve by paying in
currencies this system accepts. Every chip explains its mechanism when
applied. The preset scenarios (the three-week assignment, the gym habit, the
registration renewal) each start below threshold — your job is to rescue them.

## Lesson Plan

1. **Observe** (2 min): Load "Assignment due in 3 weeks." Read both felt values. Note which brain's value sits below threshold.
2. **Predict** (2 min): Before clicking any chip, predict which single intervention rescues it. Test.
3. **Compare** (4 min): Rescue each preset scenario with the *fewest* chips. Discuss why different tasks need different currencies.
4. **Transfer** (3 min): Each learner names one stalled real task and the chip they'll apply this week.
