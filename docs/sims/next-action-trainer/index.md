## Description

[Chapter 9](../../chapters/09-building-daily-systems/index.md) calls defining
next actions the single highest-value habit in the toolkit: most
"procrastination" on projects is an undefined next action — the starter motor
has nothing its size to grab. This trainer rehearses the skill in two modes.

**Judge mode** shows a stalled task and four candidates ("work on the
application," "think about essay topics," "open the portal and screenshot the
requirements list," "be more organized") — pick the real one, and the feedback
names the exact test each failure flunks: topic-not-action, requires further
decisions, not physically specifiable, character-goal. **Build mode** hands
you a vague project and a text box; forgiving heuristics check for a
doing-verb, a specific object, and project-smell, then ask the chain question:
*and after that?* Three links teaches the deepest lesson — you never needed to
plan the whole project, only the next ninety seconds.

## Lesson Plan

1. **Judge** (4 min): Run all six judge tasks. Tally which failure type each learner picks most.
2. **Build** (5 min): Each learner builds a three-link chain for one sim task, then for one real task from their own list.
3. **Install** (2 min): The real task's first link goes on tonight's today-list (Chapter 9's three-item rule).
