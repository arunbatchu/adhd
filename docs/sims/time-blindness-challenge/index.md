## Description

Time blindness is a felt phenomenon, so this MicroSim lets you measure your
own felt time. Round 1: click when you believe thirty seconds have passed,
while drifting shapes gently distract. Round 2: race through a
click-the-numbers task, then estimate how long it took. Round 3: *predict* how
long a repeat will take, then do it. The results panel keeps a running
felt-versus-actual ledger with signed errors — most people discover that
engaging tasks compress felt time dramatically, which is
[Chapter 3](../../chapters/03-presentations-and-traits/index.md)'s 5:52-shower
example in miniature.

The **visible clock** toggle is the fix made experiential: replay round 2 with
the clock on and the estimation error collapses. Externalized time beats felt
time — the exact principle behind the timers and departure alarms of
[Chapter 10](../../chapters/10-tools-and-system-upkeep/index.md). This is a
demonstration, not a diagnostic test.

## Lesson Plan

1. **Baseline** (4 min): All three rounds, no clock. Note each error's direction.
2. **Discuss** (3 min): Whose errors were largest during the *engaging* round? Connect to "five more minutes" that was forty.
3. **Fix** (3 min): Replay with the visible clock. Compare errors.
4. **Transfer** (2 min): Each learner names one recurring task to run an estimation log on this week (guess, time it, compare).
