## Description

[Chapter 11](../../chapters/11-emotional-life-and-identity/index.md)'s core
regulation fact: the surge peaks and begins to fall within roughly ninety
seconds *if it isn't refueled by action*. This explorer makes that steerable.
A trigger lands — the "ok" text, the boss's summons, the unpaid-bill
conversation — and the surge spikes RSD-fast. At three decision points you
choose: a pause move (draft-don't-send, "I'm taking ten," the physical dump),
a reframe (pick a plausible alternative reading and hold two hypotheses), or
acting on it now — which visibly refuels the curve.

Each scenario ends by revealing what was actually true. Deliberately, some
alarms are real — the skills' value never depended on the alarm being false:
entering a real problem at intensity 30 beats entering it at 95. The
**family view** toggle annotates each decision point with what a bystander
does that helps (reassure) versus escalates (litigate the trigger's size).
The score that matters: time above intensity 70.

## Lesson Plan

1. **Feel the physics** (3 min): Run one scenario choosing "Act on it NOW" every time. Watch the curve never land.
2. **Steer** (4 min): Replay with pause moves and reframes. Compare time-above-70.
3. **Mixed truth** (3 min): Run the unpaid-bill scenario. Discuss why the skills still paid off when the concern was real.
4. **Family view** (3 min): Re-run with the toggle on. Family members practice the reassure line out loud.
